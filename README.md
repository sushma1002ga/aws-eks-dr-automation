# AWS Multi-Region Disaster Recovery Automation

## Project Overview

This project demonstrates a production-style Disaster Recovery solution using:

- Terraform
- Amazon EKS
- Docker
- Kubernetes
- Amazon ECR
- Amazon RDS PostgreSQL
- Jenkins
- GitHub Actions
- Prometheus
- Grafana
- Route53
- AWS Lambda

The project is being built step by step as part of a complete learning series.
